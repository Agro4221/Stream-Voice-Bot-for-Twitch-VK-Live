OBS: мониторинг голоса

Бот отдаёт звук в CABLE Input, OBS забирает его через CABLE Output. Чтобы слышать этот же голос в наушниках, мониторить нужно уже источник внутри OBS — не CABLE Output обратно в OBS.
1. Settings → Audio → Advanced → Monitoring Device 2. Выбери наушники/колонки 3. Источник голоса → Monitor and Output
Не выбирай для Monitoring Device тот же вход, который OBS захватывает обратно: иначе возможны эхо или аудиопетля.

Субтитры для OBS

Для каждой дорожки можно выбрать оригинал или автоматический перевод на отдельный язык. Дорожки можно выводить одновременно через несколько Browser Source.
URL дорожки: http://127.0.0.1:8787/subtitles/ID. Для каждой дорожки можно выбрать оригинал или перевод STT на другой язык. Перевод выполняется локально через Argos Translate; нужные языковые пакеты скачиваются один раз.

STT / Субтитры

STT опционален; настройки не сбрасываются автообновлением.
Есть несохранённые изменения
Субтитры можно пока не использовать. Первый запуск модели STT может скачать модель с Hugging Face. В переносимом EXE STT работает через CPU int8, поэтому внешние CUDA/cuBLAS DLL не требуются.
