# Stream Voice Bot v1.0.2

Стабильный публичный релиз с накопленными и проверенными исправлениями после v1.0.0.

## Возможности

- Twitch Chat и Channel Points.
- Упрощённое подключение Twitch через Device Code Flow для новых подключений.
- VK Видео Live: чтение чата через локальный readonly bridge.
- Silero V5 RU TTS.
- Нормализация текста с сохранением `Ё/ё` и Unicode-акцентов.
- Очередь озвучки: пауза, продолжение, остановка, пропуск и повтор.
- Профили `Обычная` / `Громкая`.
- Регулировка громкости профилей ползунками в dB.
- Прямой аудиовывод в VB-CABLE/OBS с подготовкой 48 kHz stereo.
- faster-whisper STT с отдельными статусами загрузки и работы.
- Несколько subtitle tracks с локальным переводом через Argos Translate.
- Локальная веб-админка с сохранением пользовательских полей при автообновлении.
- Хранение секретов через Windows Credential Manager/keyring.
- Относительные пути проекта без привязки к конкретной пользовательской директории.
- Автоматическая установка Python-окружения и зависимостей.
- Восстановление npm-кэша при повреждённом пакете bridge.

## Установка

Скачайте архив релиза, распакуйте его в любую папку Windows и запустите `start_bot.bat`.

Модель `v5_ru.pt` не входит в репозиторий и скачивается установщиком отдельно.

Подробности и лицензии сторонних компонентов — в `README.md` и `THIRD_PARTY_NOTICES.md`.
