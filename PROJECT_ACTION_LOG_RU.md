# Stream Voice Bot — журнал действий и handoff

Этот файл хранит фактически выполненные действия и текущее состояние проекта, чтобы работу можно было продолжить в новом чате без потери контекста.

## 2026-09-22

### Подтверждено пользователем
- Twitch TTS работает.
- VK Видео Live TTS работает.
- Пользователь хочет сохранить ручной запуск STT кнопкой «Запустить STT».
- После нескольких экспериментальных изменений субтитры стали работать хуже; пользователь сообщил о задержке 4–5 секунд и плохом распознавании/переводе.

### Субтитры / STT
- Отменён экспериментальный SSE Browser Source.
- Отменён агрессивный алгоритм выбрасывания старого аудио.
- Восстановлен проверенный путь Browser Source через /api/state.
- Восстановлена проверенная обработка STT с chunk 2.5 сек и overlap 0.25 сек.
- Убран экспериментальный `without_timestamps=True`.
- Автозапуск STT при открытии /subtitles добавлялся временно, затем удалён по просьбе пользователя.
- Ручной запуск STT сохранён.
- Сохранены прежние Windows-исправления PortAudio/WASAPI: native/default rate, fallback устройства, resampling и COM initialization.

### UI
- Исправлен индикатор «Есть несохранённые изменения» у Silero после сохранения.
- Twitch Client ID скрыт в поле интерфейса.
- Кнопка завершения переименована в «Выключить».
- Статус завершения: «Выключение…» → «Выключен».
- После выключения показывается окно «Бот выключен».
- Twitch TTS упрощён: используется только награда «Озвучить сообщение».
- Обычный Twitch chat не является источником TTS.
- VK ordinary chat фильтруется; TTS принимается только из системного объявления ChatBot о награде.

### Windows / упаковка
- Один пользовательский `StreamVoiceBot.exe`.
- EXE собирается PyInstaller onedir.
- Silero V5 входит в пакет.
- Node нужен только для VK bridge.
- В build pipeline добавлен optional Authenticode hook. Без сертификата EXE остаётся неподписанным.
- Иконка берётся из `Agro4221/-Content-Factory` (`favicon.png`) и преобразуется в ICO на этапе Windows-сборки.
- Добавлен `Create_Desktop_Shortcut.cmd`, который создаёт `Stream Voice Bot.lnk` на рабочем столе и использует иконку EXE.

## Не менять без отдельной проверки
- Не менять рабочую логику Twitch/VK TTS.
- Не переводить STT на автостарт.
- Не возвращать SSE или агрессивный drop аудио без ручной проверки.
- Не удалять локальные большие каталоги пользователя (`dist\StreamVoiceBot_1.1.9`, `.venv` и т.п.) без явного разрешения.
- Не публиковать финальный GitHub Release до подтверждения субтитров на Windows.
