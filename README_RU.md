# Stream Voice Bot — русская версия README

Локальный Windows-бот для озвучки чата Twitch и VK Видео Live через Silero TTS с выводом в OBS.

## Быстрый старт

1. Распакуйте проект в любую папку.
2. Запустите `start_bot.bat`.
3. Откройте `http://127.0.0.1:8787`.
4. При первом запуске установщик создаст окружение и установит необходимые зависимости.

## Что умеет

- Twitch Chat и Channel Points.
- VK Видео Live chat.
- Silero V5 RU TTS.
- Очередь, повтор, пауза, продолжение, пропуск и остановка.
- Профили озвучки и громкость в dB.
- OBS через VB-CABLE.
- Опциональный faster-whisper STT.
- Несколько дорожек субтитров с переводом через Argos Translate.
- Локальное хранение секретов через Windows Credential Manager.
