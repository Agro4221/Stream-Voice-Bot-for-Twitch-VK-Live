# Быстрый старт

1. Распакуй проект в любую папку.
2. Дважды кликни `start_bot.bat`.
3. Дождись установки зависимостей и модели Silero.
4. Админка откроется автоматически; после её открытия окно запуска закроется.
5. Подключи Twitch/VK и выбери аудиоустройство.
6. Для диагностики запуска используй `start_bot_debug.bat` — он оставляет отдельную консоль с логами бота. В самой админке также есть живое окно «Подробные логи».

Проект не зависит от конкретной папки пользователя: все рабочие пути строятся относительно корня проекта.

Для OBS см. раздел OBS в `README.md`.


## Публикация на GitHub

После создания пустого Public-репозитория можно выполнить:

```powershell
.\scripts\publish_github.ps1 -GitHubRepoUrl "https://github.com/Agro4221/Stream-Voice-Bot-for-Twitch-VK-Live.git"
```

Скрипт инициализирует Git, создаст npm lockfile для VK bridge (если установлен npm),
сделает первый коммит и отправит `main` в указанный GitHub-репозиторий.
