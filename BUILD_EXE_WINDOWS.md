# Сборка Windows EXE для Stream Voice Bot

Эта ветка собрана от релиза v1.1.9 — того варианта, где кнопка «Очистить очередь» уже работала, но не показывала пользователю явного результата.

## Что получится

Сборка делает переносимый Windows-комплект:

- StreamVoiceBot.exe — единственный EXE, который нужно запускать двойным кликом.
- StreamVoiceBotCore\\ — основное приложение с Python/ML-зависимостями.
- models\\v5_ru.pt — модель Silero.
- stream_voice_bot\\web\\ — админка.
- встроенные Node.js и VK bridge находятся внутри StreamVoiceBotCore\\.
- data\\ создаётся при работе приложения и хранит базу и лог запуска.

Это сделано специально, чтобы не превращать PyTorch/Whisper/Node в хрупкий однофайловый монолит.

## Сборка на Windows

Открой PowerShell в каталоге проекта:

    powershell -ExecutionPolicy Bypass -File .\\scripts\\install_windows.ps1

Эта команда подготовит локальные Python/Node runtime, .venv, зависимости, VK bridge и модель Silero.

Затем:

    powershell -ExecutionPolicy Bypass -File .\\scripts\\build_exe.ps1

После успешной сборки готовый комплект будет здесь:

    dist\\StreamVoiceBot_1.1.9\\

ZIP для переноса:

    dist\\StreamVoiceBot_1.1.9_win64.zip

Запускать в готовом комплекте нужно:

    dist\\StreamVoiceBot_1.1.9\\StreamVoiceBot.exe

При старте EXE запускает приложение скрыто, ждёт http://127.0.0.1:8787/ и затем открывает админку в браузере.

## Если бот уже установлен и работал

Повторная установка обычно не нужна, если уже существуют:

- .venv\\
- .runtime\\node\\
- models\\v5_ru.pt

Тогда можно сразу запускать build_exe.ps1. Если скрипт сообщит, что чего-то не хватает, сначала запусти install_windows.ps1.

## Проверка готового комплекта

Перед проверкой закрой старый бот, запущенный через start_bot.bat, чтобы порт 8787 не был занят.

Затем:

1. Запусти StreamVoiceBot.exe.
2. Дождись открытия админки.
3. Проверь Twitch и VK.
4. Проверь обычную озвучку.
5. Проверь STT.
6. Проверь «Очистить очередь»: она очищает ожидающие элементы; текущая уже идущая озвучка не прерывается. Для текущего элемента используется «Стоп».
7. Проверь субтитры, если они используются.

## Что не встраивается внутрь EXE

Модель large-v3-turbo для faster-whisper в комплект не копируется. При первом запуске STT она может загрузиться в локальный .cache\\huggingface\\.

Пакеты Argos Translate для дополнительных языков также подготавливаются по запросу.

## Про «один файл EXE»

Пользователь запускает один файл — StreamVoiceBot.exe, но рядом с ним должна лежать папка StreamVoiceBotCore\\. Это намеренно: нативные ML-библиотеки, Node.js и VK bridge в таком виде стабильнее переносить как onedir-комплект.

Если потом понадобится именно один физический .exe без соседней папки, это лучше делать отдельным этапом после успешной проверки этого комплекта.
